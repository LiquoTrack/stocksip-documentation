#### 6.2.2.6. Software Deployment Evidence for Sprint Review 3 ####

Para asegurar un desarrollo estructurado y un despliegue eficiente, se organizaron los componentes del proyecto en cuatro partes principales productos: la Landing Page y las aplicaciones moviles (Kotlin y Flutter). Se adjunta el enlace para descargar directa de la aplicación móvil en Android desplegada en Github Realases: https://github.com/LiquoTrack/stocksip-android-app-distribution/releases/download/v.2.0.0/stocksip-app.apk
