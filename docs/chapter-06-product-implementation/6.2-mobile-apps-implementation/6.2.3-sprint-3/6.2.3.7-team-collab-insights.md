### Reflexión del equipo

Finalmente, se realizó una reflexión del equipo sobre el tercer sprint, donde se destacó el logro significativo de migrar exitosamente múltiples módulos críticos desde la aplicación Android nativa a la aplicación multiplataforma en Flutter. Esta transición representó un desafío técnico importante que el equipo superó con éxito gracias a la coordinación efectiva y al aprendizaje continuo de nuevas tecnologías.

- Se identificó como área de mejora la curva de aprendizaje inicial con Flutter y el patrón BLoC, lo que en algunos casos requirió más tiempo del estimado para completar ciertas funcionalidades. Sin embargo, el equipo valoró positivamente esta experiencia como una oportunidad de crecimiento profesional y adquisición de habilidades en desarrollo multiplataforma.
- El equipo reconoce que el uso de herramientas como GitHub para el control de versiones y la organización mediante ramas de funcionalidades facilitó el trabajo paralelo en múltiples módulos. La documentación técnica generada durante la migración también se considera un activo valioso para futuras expansiones del proyecto.
- El equipo valora este sprint como un hito fundamental en la evolución del proyecto, destacando que se ha logrado consolidar una base sólida en la aplicación multiplataforma que permitirá ampliar el alcance de StockSip a dispositivos iOS. Se reconoce que aún quedan módulos por migrar y funcionalidades por optimizar, pero se siente confianza en que el proyecto avanza en la dirección correcta. La capacidad demostrada para adaptarse a nuevas tecnologías y mantener la calidad del código refuerza el compromiso del equipo con la excelencia técnica y la entrega de valor continuo.
